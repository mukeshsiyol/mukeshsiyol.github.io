01 / FLAGSHIP · APPLIED AI

Remittance Evidence & Routing Assistant

An exploratory assistant for organizing remittance cases, checking supporting evidence, and preparing a traceable review. The prototype uses synthetic examples; it does not make legal determinations or validate real-world payment rules.

01Case intake
02Evidence inventory
03Source checks
04Review packet

ENGINEERING DECISION

Evidence is represented as supplied, missing, or unknown so the workflow does not silently turn absent information into a negative claim. Retrieval is limited to approved sources, and a human reviewer remains responsible for the final decision.

IMPLEMENTATION NOTE

def evidence_status(value: Optional[bool]) -> str:
    return "supplied" if value is True else (
        "missing" if value is False else "unknown"
    )

02 / FLAGSHIP · BACKEND SYSTEMS

Finance Tracker API

A role-aware finance API for transaction management, analytics, and exports, built with FastAPI and SQLAlchemy. It separates request validation and access control from the transaction service.

01HTTP client
02FastAPI routes
03JWT + role checks
04SQLAlchemy / SQLite

ENGINEERING DECISION

Viewer access is restricted before filtered transaction queries run; this keeps role policy close to the API boundary. SQLite makes local setup straightforward, while a production deployment would need a managed database and operational hardening.

05 / SMALLER BUILD · REAL-TIME DATA

Meme Aggregator

A TypeScript and Node.js service that consolidates decentralized exchange token data, caches it in Redis, and streams updates with Socket.IO. The API supports volume ordering and cursor-based retrieval.

01DEX feeds
02Normalize tokens
03Redis cache
04API + Socket.IO

ENGINEERING DECISION

Redis sorted sets support ranking by volume without sorting the full dataset on every request. Cursor-based pagination limits each response, while cached token records reduce repeated feed reads.
